# Firebase Admin SDK Configuration

Đặt file private key `firebase-adminsdk.json` tải từ Firebase Console vào thư mục này:

1. Vào Firebase Console -> Project Settings (⚙️) -> Service accounts
2. Nhấn "Generate new private key"
3. Đổi tên file tải về thành `firebase-adminsdk.json` và lưu vào thư mục `backend_api/backend_api/Config/firebase-adminsdk.json`
